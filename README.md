# 🔐 LogitPass

**Gestor de contraseñas de código abierto para Android.**

LogitPass es un proyecto centrado en la privacidad, el almacenamiento local y la protección de credenciales. Su objetivo es ofrecer una forma sencilla de gestionar contraseñas desde Android, sin depender de una cuenta en la nube.

## ✨ Características

- 🔒 **Bóveda de contraseñas:** organiza tus credenciales desde la aplicación.
- 🛡️ **Protección mediante contraseña maestra:** acceso protegido a la bóveda.
- 👆 **Desbloqueo biométrico:** acceso mediante biometría en dispositivos compatibles.
- 🎲 **Generador de contraseñas:** crea contraseñas nuevas desde la aplicación.
- 🔎 **Auditoría de seguridad:** herramientas para revisar la seguridad de las credenciales.
- 📱 **Autorrelleno:** funciones de asistencia al introducir credenciales, según la compatibilidad.
- 💾 **Enfoque local:** diseñado para priorizar la privacidad y reducir la dependencia de servicios externos.

## 🧪 Estado del proyecto

LogitPass se encuentra en una fase inicial de desarrollo y evaluación. La primera versión pública sirve como punto de partida para probar la aplicación, detectar problemas y mejorar su seguridad.

**Importante:** no se ha presentado como una aplicación sometida a una auditoría de seguridad independiente. No utilices todavía contraseñas críticas o credenciales reales de alto valor.

## 🔓 Código abierto

El código fuente está disponible públicamente en GitHub. Puedes revisarlo, informar de errores y proponer mejoras mediante los mecanismos del repositorio.

## 🐛 Informar de errores

Si encuentras un fallo o tienes una sugerencia, abre una incidencia en la pestaña **Issues** del repositorio e incluye los pasos necesarios para reproducir el problema, sin compartir contraseñas ni datos privados.

## 🎯 Objetivo

Crear una herramienta de gestión de contraseñas sencilla, accesible y centrada en la privacidad, mejorándola progresivamente mediante el desarrollo y la revisión del código.
